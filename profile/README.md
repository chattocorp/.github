# ChattoCorp

## Chatto

We build Chatto, an open-source chat app for teams and communities. You can host it on your own server to give your group a place to exchange messages and join voice and video calls.

[Visit the Chatto website](https://chatto.run) · [Explore the source code](https://github.com/chattocorp/chatto)

## Geordi

Geordi is a desktop app for working with coding agents. Each agent gets its own Git worktree and branch, so you can run tasks side by side. Follow the diff as an agent works, steer it in the conversation, and track its pull request from the same workspace.

[Explore Geordi on GitHub](https://github.com/chattocorp/geordi)

## Sweet Release

Sweet Release is a command-line tool for managing releases. Write a short Markdown note alongside a change, and Sweet uses it to calculate the next version and generate the changelog. Packages in the same repository can each have their own release cycle.

[Explore Sweet Release on GitHub](https://github.com/chattocorp/sweet-release)
